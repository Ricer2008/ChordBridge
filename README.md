# ChordBridge 🎸

吉他谱多维度转换与预览工具：**简谱 / 五线谱 / 六线单音谱 / 六线和弦谱** 智能互转 + **MIDI 合成预览**。

跨平台桌面应用（Tauri 2 + Rust 乐理核心 + 前端 SVG 渲染）。

## 快速开始

### 方式一：浏览器预览（无需编译，最快）

```bash
npm run web
# 打开 http://localhost:5173
```

### 方式二：桌面应用（Tauri 开发模式）

```bash
npm install          # 首次需要
npm run tauri dev    # 首次编译较久（约 5-10 分钟）
```

### 运行乐理核心单元测试

```bash
cd src-tauri/theory && cargo test
```

## 使用说明

| 输入 | 说明 |
|------|------|
| 简谱主旋律 | 空格分隔的 `1-7`，升降号 `#`/`b`（前缀或后缀均可），`'` 升八度、`,` 降八度。示例：`1 2 3# b7 5' 6,` |
| 和弦标记 | `[位置:和弦名]`，位置为 1-based 音符序号。示例：`[1:C] [5:G7] [9:Am]` |
| 调号 | 全部大小调（小调按关系大调处理调号，符合五度循环） |
| 八度 | -1 ~ 3 全局偏移（C4 = 中央C） |
| 节拍 / BPM | 4/4、3/4、2/4、6/8；BPM 40~240 |
| 把位偏好 | 低把位（0-4品）/ 高把位（5品+） |

点击「生成」→ 四类谱面**同步**输出；任一输入非法则弹窗提示并高亮错误 token，**不做部分生成**。

## 导出

- 每张谱面可单独导出 **PNG（300 DPI）** 或 **SVG 矢量图**
- 「全部导出 ZIP」打包 4×SVG + 4×PNG + 标准 MIDI 文件（.mid，尼龙吉他音色）

## 乐理规则要点

- **五度循环调号**：G 大调自动含 F#，F 大调含 Bb……小调映射到关系大调
- **音高映射**：简谱 `1` = 调主音，主音落在最接近中央 C 的八度
- **指板查找**：标准调弦 EADGBE，低于 E2 的音自动升八度兜底（谱面以金色标注）
- **未收录和弦**：显示和弦名 + "(未收录)"，不会崩溃
